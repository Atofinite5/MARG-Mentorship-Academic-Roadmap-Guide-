MARG (Mentorship & Academic Roadmap Guide) is an Al-powered academic and career guidance system designed to help students explore future pathways with confidence. Using the Gemini API, MARG provides personalized career insights, structured recommendations,and college suggestions tailored to each student's stage, location, andquiz responses. The system offers an interactive chat interface,detailed career breakdowns, and quiz-based guidance, making it acomplete roadmap companion for students.
The backend is built with Node.js, integrating AI logic, structured data, and clean API routes. It features modules for chat handling, career information retrieval, and JSON-based quiz recommendations. The frontend guides students through onboarding, chatting with MARG, taking quizzes, and viewing curated results including colleges and resources. Admin tools allow mentors to monitor trends, update datasets, and ensure content quality.
MARG emphasizes reliability through strict JSON validation, logging of AI responses, environment-based configuration, and safety fallbacks for errors. It is designed for scalability, maintainability, and future enhancements like localization, richer college data, mentor review workflows, and analytics dashboards. The system serves as a smart, adaptable bridge between student aspirations and actionable academic pathways.
