MARG – Mentorship & Academic Roadmap Guide (AI-Powered Student Guidance System)

Overview

MARG is an AI-driven academic and career guidance platform designed to help students explore future pathways with clarity and confidence. Powered by the Gemini API, it delivers personalized insights, structured recommendations, and college suggestions tailored to each student’s stage, location, and quiz responses.

⸻

Core Features
	•	AI-powered chat interface for real-time academic and career guidance
	•	Personalized recommendations based on quizzes, user profile, and academic interests
	•	Detailed career breakdowns including skills, salary ranges, and growth paths
	•	College suggestions customized by location, stream, and eligibility
	•	Interactive onboarding flow guiding students from entry to results
	•	Mentor/admin tools for updating datasets, checking trends, and ensuring content quality

⸻

Backend Architecture (Node.js)
	•	Built using Node.js with modular architecture
	•	Gemini AI integration for generating insights and structured outputs
	•	Clean and optimized REST API routes
	•	Modules for:
	•	Chat handling
	•	Career data retrieval
	•	Quiz logic & scoring
	•	Recommendation building
	•	JSON-based knowledge datasets for career and college information

⸻

Frontend Functionality
	•	Smooth student onboarding
	•	AI chat interface with guided prompts
	•	Quiz system for personalized results
	•	Dedicated screens for:
	•	Career insights
	•	College lists
	•	Suggested resources
	•	Simple and intuitive UI for maximum student engagement

⸻

Reliability & Quality Measures
	•	Strict JSON validation to maintain data quality
	•	AI response logging for debugging and transparency
	•	Environment-based configuration for secure deployment
	•	Safety fallbacks to handle errors gracefully

⸻

Scalability & Future Enhancements
	•	Multi-language localization
	•	Expanded college dataset
	•	Mentor review & approval workflows
	•	Analytics dashboards for student progress
	•	Improved recommendation engine

⸻

Purpose

MARG acts as a smart, adaptable bridge between student aspirations and actionable academic pathways, making it a complete AI-based academic roadmap companion.
